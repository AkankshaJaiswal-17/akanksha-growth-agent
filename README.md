Akanksha's Growth Agent 🚀

A beginner-friendly Python task management application built to practice programming fundamentals, error handling, and data persistence.

📌 About the Project

Akanksha's Growth Agent helps users manage tasks, mark tasks as completed, and save feedback ratings. It uses JSON files to preserve data between program runs.

✨ Features

- Add new tasks
- View all pending tasks
- Complete tasks
- Prevent empty and duplicate tasks
- Rate the task-completion experience
- View saved feedback
- Handle invalid menu input
- Save tasks and feedback using JSON files
- Preserve data when the program restarts

🛠️ Technologies Used

- Python
- JSON
- Git
- GitHub

▶️ How to Run

1. Install Python 3 if it is not already installed.

2. Clone or download this repository.

3. Open the project folder in VS Code.

4. Run the application using:
   
   python main.py
   
   If that command doesn't work on Windows, try:
   
   py main.py

📂 Project Files

- "main.py" — application logic and menu
- ".gitignore" — specifies files Git should ignore
- "tasks.json" — stores task data locally
- "feedback.json" — stores feedback locally

The JSON files are created when the application saves data.
